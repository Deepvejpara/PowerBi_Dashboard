# 📊 Power BI Dashboard Project

🔗 **Live Dashboard:** [https://deepvejpara.github.io/PowerBi\_Dashboard/](https://deepvejpara.github.io/PowerBi_Dashboard/)

This project presents an **interactive Power BI dashboard** built using a structured dataset. The focus is on **data modeling, DAX calculations, and meaningful visual insights** rather than heavy visual design.

---

## 🎯 Project Objective

The objective of this project is to:

- Analyze structured data using Power BI
- Build relationships between fact and dimension tables
- Create meaningful KPIs and measures using DAX
- Present insights through a clean and interactive dashboard

---

## 📁 Files Included

- **FinalProject\_Dataset.xlsx** — Source dataset used for analysis
- **DashBoard.pbix** — Power BI report containing the data model, DAX measures, and dashboard visuals

---

## 🧩 Data Model Overview

The project uses a **star schema–based data model** for efficient analysis and reporting.



*Figure: Power BI model view showing fact and dimension table relationships.*

---

## 📐 DAX & Calculations

The following DAX concepts are implemented:

- Calculated measures for KPIs
- Aggregations (SUM, AVERAGE, COUNT)
- Logical conditions using IF / SWITCH
- Filter context handling using CALCULATE
- Time-based analysis (where applicable)

## ▶️ How to Use

1. Download **FinalProject\_Dataset.xlsx** and **DashBoard.pbix**
2. Open `DashBoard.pbix` in **Power BI Desktop**
3. Refresh the data if needed
4. Interact with slicers and visuals to explore insights
